# 新项目开工

用本模板开一个新 AVG 的步骤。全部在编辑器或文本编辑器里完成，不需要改框架代码。

## 1. 得到一份副本

任选其一：

- 克隆：`git clone <模板仓库> 新游戏目录`，进入后 `git lfs install`、`git lfs pull`。
- 直接复制整个目录（不需要 `dist/`、`staging/`、`cangqi/`、`game/.godot/`）。

用副本里的 `启动编辑器.ps1` 打开。第一次会全量导入；若 Dialogic 的 .dtl 在文件系统面板里不显示，执行 项目 → 重新加载当前项目。

## 2. 改名（必须）

| 位置 | 改什么 |
|---|---|
| 项目设置 → 应用 → 配置 → 名称（`project.godot` 的 `config/name`） | 游戏名。**存档目录按它区分**，不改会和模板或别的项目共用存档 |
| 项目 → 导出 → Windows Desktop | 导出路径文件名、产品名称、文件描述、图标 |
| `导出Windows.ps1` 里的 `AVGGame.exe` | 与上一项保持一致 |
| `DialogicFantasyMenu/main_menu.tscn` 的 Title_Part1/2/3 | 标题画面文字 |
| 同场景 AboutTab 下的 RichTextLabel | 制作人员页 |

## 3. 指定开场时间线

在 `game/content/` 新建时间线（Dialogic → Timeline → Create New Timeline），例如 `Start.dtl`。

然后打开 `DialogicFantasyMenu/main_menu.gd`，把 `beginning_timeline` 的默认值从 `"FrameworkExample"` 改成你的时间线名（如 `"Start"`）。“开始游戏”会从这里进入。

时间线结束时用 `[signal arg="GAME_END"]` 回到标题。

## 4. 去掉示例（可选）

示例留着不影响新内容，也可作参考。要删干净：

1. 删除 `game/examples/` 整个目录。
2. 项目设置 → 自动加载：移除 `ExampleBridge`。
3. Dialogic → Settings：清掉指向 examples 的人物、时间线目录项（或直接编辑 `project.godot` 的 `dialogic/directories/dch_directory`、`dtl_directory`）；Glossary 里移除 `test_glossary.tres`。
4. Dialogic → Variables：`PongResult`、`TextInput` 不需要可删。
5. **至少建一个自己的角色**，或在 Dialogic → Settings → Text 关闭 Autocolor Names。否则一个角色都没有时 Dialogic alpha 20 会在显示对白时报错。

以上步骤在副本上测过：删掉示例后标题菜单、鉴赏页和新时间线都正常。

## 5. 内容放哪

| 内容 | 位置 |
|---|---|
| 时间线 .dtl、角色 .dch | `game/content/`，可自建子目录 |
| 立绘、背景、CG、音乐、语音 | `game/content/` 下自建 `characters/`、`backgrounds/`、`audio/` 等 |
| 鉴赏条目（TimelineMeta .tres） | `game/content/gallery/`，鉴赏页自动读取 |
| 小游戏场景 | `game/content/minigames/`，接入方式照 `examples/integration/` |
| 界面皮肤 | 替换 `game/Assets/` 下同名贴图，或改 `DialogicFantasyStyle/` |

素材许可记在 `licenses/`，导出时整个目录会一起复制。

## 6. 版本管理

新项目建议立刻建自己的仓库：

```bash
git init -b main
git lfs install --local
git add -A && git commit -m "从 AVG 模板开工"
```

模板自带的 `.gitignore`、`.gitattributes`（LFS 规则）直接沿用。
